# c-programming-pointers
This program is used to add two numbers using pointers in C.

First, we declare three variables a, b, and sum to store two numbers and their addition result.

Then we declare two pointer variables p1 and p2.

The program asks the user to enter two numbers. After getting the numbers, we store the address of a in p1 and the address of b in p2.

Using *p1 and *p2, we get the values of those two variables and add them together.

Finally, the answer is stored in sum and displayed on the screen.

In simple words: This program adds two numbers using pointers by accessing the values through their addresses.
